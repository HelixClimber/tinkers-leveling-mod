# Tinkers' Leveling — Tool XP Mod

[![Download Latest](https://img.shields.io/github/v/release/HelixClimber/tinkers-leveling-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/HelixClimber/tinkers-leveling-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Earn XP by using Tinkers' Construct tools and unlock additional modifier slots as they level up.

## Features

- Tools gain XP from every mining, chopping, or attack
- Reach levels to unlock bonus modifier slots
- Level bar displayed in the Tinkers' tool tooltip
- Config to control XP rates and max tool level
- Compatible with TiC 2 and later versions

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
